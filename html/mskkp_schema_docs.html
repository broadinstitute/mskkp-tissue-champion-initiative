mskkp-rnaseq-gold-standard

Standard for single-cell / single-nucleus RNA-seq reference datasets across musculoskeletal tissue types. Defines object layout, required metadata, and the quality thresholds that qualify a dataset as a tissue "champion".

Statusdraft Applies tomusculoskeletal tissues (7 champions)

Maintained by Jeremy Arbesfeld (Knowledge Portal Network) (initiative lead) · Luca Tucciarone (Gaulton Lab) (schema author).

How to read this spec

A conforming dataset is a single serialized object (an AnnData .h5ad or a Seurat .rds) that carries an expression matrix plus structured metadata about every cell, gene, and donor. Each section below documents one part of that object and marks every field as Required Recommended or Optional.

Two tiers of conformance

The standard separates “is this a valid dataset” from “is this good enough to be the reference”. Every field and rule below belongs to one of these tiers.

1 · Required structure

The minimum any dataset must contain to be valid against the standard. A tissue may hold many conforming datasets.

See required structure →
2 · Champion criteria

The higher quality bar a dataset must clear to be blessed as that tissue’s single reference (“champion”) dataset.

See champion criteria →

Data object — formats & matrices

A dataset is delivered as one serialized object. Two formats are accepted so neither Python nor R users need to change toolkits.

.h5adAnnData · Pythonpreferred
.rdsSeurat · Raccepted equivalent

Expression matrices

FieldRequirementTypeDescription
raw_countsRequiredintegerUnnormalized integer UMI counts.
Location — h5ad: adata.layers["counts"] · Seurat: obj[["RNA"]]@counts
normalizedRequiredfloatLog-normalized expression (Seurat “data” slot equivalent). Default method LogNormalize, scale factor 10000.
Location — h5ad: adata.X · Seurat: obj[["RNA"]]@data
If raw counts are stored in adata.X instead of a layer, declare that in uns.schema.X_holds. Exactly one location must hold the raw integer counts.

Cell-type labels obs

Every cell carries two labels, from broad to specific. Think Country → City: a broad category, then the specific subtype inside it. Every Level 2 label must sit under exactly one Level 1 label.

Level 1celltype

The broad category — the general kind of cell, e.g. Myonucleus Immune.

→
Level 2cell_subtype

The specific subtype inside it, e.g. Myonucleus-Type-I Macrophage.

FieldRequirementTypeDescription
celltypeRequiredcategoricalLevel 1 — broad cell-type label (the general category).
Maps to Cell Ontology (CL) where possible.
cell_subtypeRequiredcategoricalLevel 2 — specific subtype within the celltype; nests under exactly one celltype.
Maps to Cell Ontology (CL) where possible.

Deeper levels (Level 3 and beyond) are allowed but not required.

Gene identifiers var

Genes are keyed by a stable identifier, not by symbol. The readable English symbol travels alongside. Use gene_id as the canonical key everywhere it matters — matching genes and merging datasets across tissues.

FieldRequirementTypeDescription
gene_idRequiredstring &middot; keyStable gene identifier used as the gene key — an HGNC ID (e.g. HGNC:7577) or an Ensembl gene ID (e.g. ENSG00000092054).
Record which system in uns.schema.gene_id_system.
gene_symbolRequiredstringHuman-readable English symbol for the gene_id (e.g. MYH7). For readability only.
mtOptionalbooleanFlags mitochondrial genes (used to compute percent.mt).
highly_variableOptionalbooleanHighly variable genes, if computed.

Dataset info uns

Dataset-level provenance describing which conventions this object follows.

FieldRequirementTypeDescription
schemaRequiredblockProvenance block naming this standard and any deviations.
Fields: standard, version, tissue, gene_id_system (hgnc | ensembl), X_holds (normalized | raw).
donor_metadataOptionaltableDonor-indexed summary table (one row per donor_id).

What a filled-in block looks like

The table above lists the menu of choices; a real dataset fills in one value per field. The two “pick one” fields do the real work later — gene_id_system tells anyone combining tissues whether gene IDs must be mapped before matching, and X_holds tells a tool whether adata.X is ready to use or still needs normalizing.

Example · a filled-in uns.schema (skeletal-muscle dataset)
standard:       mskkp-rnaseq-gold-standard
version:        0.1.0-draft
tissue:         skeletal_muscle
gene_id_system: ensembl  # one of  hgnc | ensembl  — this set keys genes by Ensembl IDs
X_holds:        normalized  # one of  normalized | raw  — what adata.X contains
The same block set in Python / AnnData
adata.uns["schema"] = {
    "standard":       "mskkp-rnaseq-gold-standard",
    "version":        "0.1.0-draft",
    "tissue":         "skeletal_muscle",
    "gene_id_system": "ensembl",
    "X_holds":        "normalized",
}  # Seurat equivalent: obj@misc$schema

Required structure Tier 1

The minimum for a dataset to be valid against the standard. All must hold.

  • object.formats is one of [h5ad, rds]
  • object.matrices.raw_counts present
  • object.matrices.normalized present
  • obs.annotations has both celltype (broad) and cell_subtype (specific) present
  • obs.donor.donor_id present
  • obs.donor.assay present
  • obs.qc_metrics.nCount_RNA present
  • obs.qc_metrics.nFeature_RNA present
  • uns.schema present

Champion criteria Tier 2

The extra bar to qualify as a tissue’s reference dataset. Every Required rule must pass; Recommended rules are reported but do not block. Note the two mitochondrial rules are gated by the assay field.

RuleWhat it checksTestApplies whenSeverity
min_countsEvery cell has more than 500 total counts.min(obs.nCount_RNA) > 500—Required
max_mito_snRNAMitochondrial fraction under 3% for single-nucleus assays.max(obs.percent.mt) < 3%obs.assay == "snRNA-seq"Required
max_mito_scRNAMitochondrial fraction under 15% for single-cell assays.max(obs.percent.mt) < 15%obs.assay == "scRNA-seq"Required
annotation_depthBoth label layers are present — a broad celltype AND a specific cell_subtype (not just one of them).obs.annotations.levels >= 2—Required
clusters_well_definedEach subtype nests under exactly one celltype and is represented by a reasonable number of cells (proxy for "clearly defined clusters").• every cell_subtype maps to exactly one celltype
• min cells per cell_subtype >= 20		—Required
donor_countAt least 10 donors.unique(obs.donor_id) >= 10—Required
control_and_diseaseIncludes Control and, where available, disease donors.contains "Control" and >= 2 distinct values—Recommended
cell_countAt least 50,000 cells.count(cells) >= 50000—Required

Tissue profiles

The only tissue-specific part of the standard: one block per musculoskeletal tissue, owned by that tissue’s champion. Each defines the assay, disease conditions, and the two-level cell ontology for that tissue.

Draft seeds — review required. Skeletal muscle is a fully worked example. The other six blocks are pre-seeded with well-established starter populations only to show the pattern. Each champion must review their block line by line — especially the disease conditions and the cell ontology (celltypes, subtypes, and markers) — and set the block status to confirmed. Seeded markers are shown by symbol and must be recorded as gene_ids in the delivered data.
