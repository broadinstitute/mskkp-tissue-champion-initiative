How to read this spec

A conforming dataset is a single serialized object (an AnnData .h5ad, a Seurat .rds, or a SingleCellExperiment .rds) that carries an expression matrix plus structured metadata about every cell, gene, and donor. Each section below documents one part of that object and marks every field as Required or Optional. All of it is generated from the LinkML schema and companion data files in schemas/ — edit those, then regenerate this page with python3 docs/build_docs.py, not this page directly.

Two tiers of conformance

The standard separates “is this a valid dataset” from “is this good enough to be the reference”. Every field and rule below belongs to one of these tiers.

1 · Required structure

The minimum any dataset must contain to be valid against the standard. A tissue may hold many conforming datasets.

See required structure →
2 · Champion criteria

The higher quality bar a dataset must clear to be blessed as that tissue’s single reference (“champion”) dataset.

See champion criteria →

Cell-type labels obs

Every cell carries two author-provided labels, from broad to specific. Think Country → City: a broad category, then the specific subtype inside it. Every Level 2 label must sit under exactly one Level 1 label. Each level also has a companion ontology_* field mapping the free-text label to its nearest Cell Ontology (CL) term, to support harmonization across datasets.

Level 1author_celltype

The broad category — the general kind of cell, e.g. Myonucleus Immune.

→
Level 2author_cell_subtype

The specific subtype inside it, e.g. Myonucleus-Type-I Macrophage.

Champion criteria Tier 2

The extra bar to qualify as a tissue’s reference dataset. Every Required rule must pass; Recommended rules are reported but do not block. These are aggregate checks over obs that LinkML itself can't express — see schemas/validate_champion_criteria.py for the runnable checker.

Tissue profiles

The only tissue-specific part of the standard: one block per musculoskeletal tissue, owned by that tissue’s champion. Each defines the assay, disease conditions, and the two-level cell ontology for that tissue.

Draft seeds — review required. Skeletal muscle is a fully worked example. The other six blocks are pre-seeded with well-established starter populations only to show the pattern. Each champion must review their block line by line — especially the disease conditions and the cell ontology (celltypes, subtypes, and markers). Seeded markers are shown by symbol and must be recorded as gene_ids in the delivered data.
